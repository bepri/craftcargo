# debcraft.yaml schema

This page documents the structure of the `debcraft.yaml` file generated by craftcargo.

## Top-level fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | yes | Source package name |
| `version` | string | yes | Upstream version |
| `summary` | string | no | Short one-line description |
| `description` | string | no | Long description |
| `contact` | string | no | Maintainer contact |
| `uploaders` | list | no | Additional uploaders |
| `source-type` | string | yes | Always `rust-crate` |
| `issues` | string | no | Bug tracker URL |
| `source-url` | string | no | Upstream source URL |
| `vcs-git` | string | no | VCS repository URL |
| `homepage` | string | no | Project homepage URL |
| `licence` | string | no | SPDX licence expression |
| `parts` | map | no | Build parts (see below) |
| `packages` | map | no | Binary package definitions |

## Parts

The `parts` section defines build steps. Each part has:

| Field | Type | Description |
|-------|------|-------------|
| `plugin` | string | Build plugin (e.g. `rust`) |
| `source` | string | Source location |
| `build-packages` | list | Packages needed at build time |
| `stage-packages` | list | Packages needed at runtime |
| `after` | list | Parts that must build first |
| `organize` | map | File relocation mapping |

## Packages

The `packages` section defines binary packages:

| Field | Type | Description |
|-------|------|-------------|
| `description` | string | Package description |
| `depends` | list | Runtime dependencies |
| `multi-arch` | string | Multi-arch value (`same`, `foreign`, `no`) |
| `build-profiles` | list | Conditional build profiles |

## Example

```yaml
name: rust-ripgrep
version: "14.1.0"
summary: Fast line-oriented search tool
description: |
  ripgrep recursively searches directories for a regex pattern
  while respecting gitignore rules.
contact: "maintainer@example.com"
source-type: rust-crate
homepage: "https://github.com/BurntSushi/ripgrep"
vcs-git: "https://salsa.debian.org/rust-team/debcargo-conf.git"
issues: "https://github.com/BurntSushi/ripgrep/issues"
licence: MIT OR Unlicense

parts:
  ripgrep:
    plugin: rust
    source: "https://crates.io/api/v1/crates/ripgrep/14.1.0/download"
    build-packages:
      - librust-regex-dev

packages:
  ripgrep:
    description: Fast line-oriented search tool
    depends:
      - libc6
```
